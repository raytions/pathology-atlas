Task · Clinical task

Lymph-node metastasis detection

Finding tumour deposits in sentinel lymph node sections. Benchmarks score it either per slide (is there a metastasis?) or per lesion (where is each one?), and the two settings need different annotations.[c16-jama]

Prediction target
Presence of metastasis per slide; optionally the location of each lesion.
Organ
Breast
Disease
Breast cancer lymph-node metastasis
Task family
Weakly supervised slide classification

  • CAMELYON16

    Dataset

    Sentinel lymph node WSIs from two Dutch hospitals with exhaustive metastasis contours, built for the first WSI challenge in computational pathology. Small, well annotated and still the default sanity check for slide-level metastasis detection.

    Organ
    Breast
    Task
    Lymph-node metastasis detection
    Annotation
    Slide label, Lesion contours
    Access
    Open download

    WSI399 slides · 399 patientsCC0

  • CAMELYON17

    Dataset

    A five-centre extension of CAMELYON16 that moves from single slides to patients: slides are grouped into artificial patients and scored by pN stage. Useful for testing robustness across centres and scanners.

    Organ
    Breast
    Task
    Lymph-node metastasis detection, Patient-level pN staging
    Annotation
    Slide label, Patient label, Lesion contours
    Access
    Open download

    WSI1,000 slides · 200 patientsCC0
