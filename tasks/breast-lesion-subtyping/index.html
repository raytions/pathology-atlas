Task · Clinical task

Breast lesion subtyping

Classifying breast tissue into lesion categories at slide or region level. Coarse and fine-grained label sets are both in use, so check which one a reported number refers to.[bracs-preprint]

Prediction target
Lesion type (benign / atypical / malignant) or one of seven finer subtypes.
Organ
Breast
Disease
Breast lesions (benign, atypical, malignant)
Task family
Weakly supervised slide classification, ROI / patch classification
