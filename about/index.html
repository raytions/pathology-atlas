About

A resource atlas, edited like a reference work

Pathology Atlas helps computational pathology researchers find usable data, reproducible methods and the papers behind them, starting from an organ, a disease or a task. It is deliberately small: 7 datasets and15 methods in this release, each checked against primary sources.

It is a static site. There is no account, no tracking, no hosted slide viewer and no mirrored data. Links go to the official portals.

Editorial policy

Sources come first

Awesome lists and aggregators are used only to discover candidates. Facts are checked against the original paper, the project or challenge site, the official repository, the model card or the data portal. Each scale figure, access route, licence and dataset relation names the source it came from.

Original writing

Summaries are written by the editors. We do not paste abstracts or README text, and we do not reproduce figures or pathology images whose licence is unclear. Illustrations on this site are original, abstract drawings.

Unknown means unknown

A field we have not confirmed reads Not verified. We do not estimate counts, infer licences or fill gaps from memory. last_verified is only set on the date an editor actually checked the sources.

Review status

Verified
Sources checked; shown on the public site and in list search.
Needs review
Drafted from primary sources, awaiting a second check. Kept in the repository only.
Draft
Candidate found during discovery. Kept in the repository only.

What a relation means

Every method-dataset relation records one use and the source that states it. A method can have several relations; each is shown with its own label, and the relation row on the method page links to its evidence.

Evaluation
A cited source reports evaluating the method on this dataset for the stated task.
Fine-tuning
A cited source reports fine-tuning or training the method on this dataset. Not by itself an evaluation result.
Pretraining
The dataset was part of the pretraining data. Says nothing about downstream performance on it.
Background
Context only: definitions, grading systems or related work. Not a method result.
Same task family
Built for this kind of task. No relation to this dataset is recorded; do not read it as evaluated.

Corrections and new entries

Entries live as YAML and Markdown files in the repository and are validated at build time for duplicate IDs, invalid values, broken links between entries and facts without a source. New entries start as draft and only become public after review. See the repository README for the workflow.
