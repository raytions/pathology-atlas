Organ topic

Colorectum

Patch-level tissue classification on H&E, with a training set and an independent test set released together.

Colorectal cancer tissue is a mosaic: tumour epithelium sits next to stroma, mucus, muscle, lymphocytes, fat, debris and normal mucosa. Telling these apart on small patches is the first step in many pipelines, for example to measure how much of a tumour is stroma before relating that to outcome.

The two datasets below are tile collections, not slide collections. Each released image is a 224 x 224 patch with one tissue label, cut from regions that a blinded observer outlined by hand. Treat the larger set as training data and the smaller one as the external test set: they come from different patients, and the release itself suggests that use.

Before comparing numbers across papers, check two things the cards below record: whether a model used the colour-normalised or the unnormalised training images, and whether it reports balanced accuracy, since the classes are only roughly balanced.

Datasets

Open as a filtered list →

  • CRC-VAL-HE-7K

    Dataset

    7,180 H&E patches with the same nine tissue classes, size and resolution as NCT-CRC-HE-100K, from colorectal adenocarcinoma patients who do not appear in that set. Released as its external test set, and it is the test split behind most reported colorectal tissue-classification results catalogued here.

  • NCT-CRC-HE-100K

    Dataset

    100,000 non-overlapping 224 x 224 H&E patches at 0.5 microns per pixel, each labelled with one of nine tissue classes, cut from hand-delineated regions of 86 slides. Released in a colour-normalised version and an unnormalised version; it is the usual training set for colorectal tissue classification.
