Dataset

SICAPv2

SICAP v2 · SICAP

Prostate core-needle biopsy patches (512 x 512 at 10x) from 155 slides of 95 patients, each with a pixel-level Gleason grade mask, plus a primary and secondary Gleason grade per slide and a patient-level train / validation / test partition proposed by the authors.

Official entry

data.mendeley.com/datasets/9xxm58dvs3/2

Primary paper

Silva-Rodríguez J. et al. Going deeper through the Gleason scoring scale: an automatic end-to-end system for histology prostate grading and cribriform pattern detection. Comput Methods Programs Biomed 195, 105637 (2020)

Version & evaluation

Version
Mendeley Data version 2 (published 2020-10-22, DOI 10.17632/9xxm58dvs3.2); version 1 was published 2020-07-20. The readme inside the archive is headed "Version 1, 2020-05".[sicap-mendeley]The record does not describe what changed between Mendeley versions; only the version 2 archive listing was inspected.
Official splits
Patient-based partition shipped as spreadsheets. Test fold, 9,959 train patches from 124 slides and 2,122 test patches from 31 slides; plus four validation folds (Val1 to Val4) for cross-validation.[sicap-archive]Matches preprint Section 4.1 / Table 3. Non-cancerous patches in the partition come only from non-cancerous slides; cancerous patch labels are the majority grade of the mask.
Evaluation protocol
Patch-level Gleason grade (non-cancerous, 3, 4, 5) and biopsy-level Gleason score, both reported with quadratic Cohen's kappa in the source paper.[sicap-preprint]

Known limitations

  • Despite the record title, the archive contains patches, masks and label tables, not whole-slide image files.[sicap-archive]
  • Single institution and a single scanner model, so site and scanner shift are not represented.[sicap-preprint]
  • Patch labels are derived from the masks by majority vote; patches with under 20 % tissue were not extracted.[sicap-archive]
  • Cribriform-pattern labels exist only for a subset of Gleason 4 patches (G4C column in the partition tables).[sicap-archive]
  • The preprint's per-class patch totals in the text (10,339 in all) do not match its Table 3 (12,081); the released partition files match Table 3.[sicap-preprint]
