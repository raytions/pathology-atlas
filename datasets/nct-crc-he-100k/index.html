Dataset

NCT-CRC-HE-100K

CRC-100K (training set) · NCT-CRC-HE-100K-NONORM

100,000 non-overlapping 224 x 224 H&E patches at 0.5 microns per pixel, each labelled with one of nine tissue classes, cut from hand-delineated regions of 86 slides. Released in a colour-normalised version and an unnormalised version; it is the usual training set for colorectal tissue classification.

Version & evaluation

Version
Zenodo v0.1 (2018-04-07, DOI 10.5281/zenodo.1214456). Two variants, Macenko colour-normalised (NCT-CRC-HE-100K) and unnormalised (NCT-CRC-HE-100K-NONORM).[zenodo-crc]The variants come from the same raw data, but tiles were selected stochastically, so their image regions are not identical.
Official splits
No internal split is defined. The record suggests CRC-VAL-HE-7K as the validation set for models trained on this set.[zenodo-crc]Kather et al. 2019 split it 70 / 15 / 15 internally for model selection only.
Evaluation protocol
Nine-class patch classification. The record warns that classes are only roughly balanced and that accuracy on the full set alone should not be used.[zenodo-crc]

Known limitations

  • Not purely colorectal tissue. Liver-metastasis slides and gastrectomy normal tissue were included to add variability.[zenodo-crc]
  • Patches come from hand-delineated single-tissue regions, so each image shows essentially one tissue type; this is easier than classifying arbitrary tiles from a whole slide.[kather-paper]
