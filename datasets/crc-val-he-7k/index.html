Dataset

CRC-VAL-HE-7K

CRC-100K (test set)

7,180 H&E patches with the same nine tissue classes, size and resolution as NCT-CRC-HE-100K, from colorectal adenocarcinoma patients who do not appear in that set. Released as its external test set, and it is the test split behind most reported colorectal tissue-classification results catalogued here.

Official entry

doi.org/10.5281/zenodo.1214456

Primary paper

Kather J. N. et al. Predicting survival from colorectal cancer histology slides using deep learning: a retrospective multicenter study. PLoS Med 16, e1002730 (2019)

Version & evaluation

Version
Zenodo v0.1 (2018-04-07, DOI 10.5281/zenodo.1214456), a single file in the same record as NCT-CRC-HE-100K.[zenodo-crc]
Official splits
Intended as the validation / external test set for models trained on NCT-CRC-HE-100K.[zenodo-crc]
Evaluation protocol
Nine-class patch classification on all 7,180 patches. Kather et al. 2019 report overall nine-class accuracy for a VGG19 trained on NCT-CRC-HE-100K.[kather-paper]

Datasets for the same task

  • NCT-CRC-HE-100K

    Dataset

    100,000 non-overlapping 224 x 224 H&E patches at 0.5 microns per pixel, each labelled with one of nine tissue classes, cut from hand-delineated regions of 86 slides. Released in a colour-normalised version and an unnormalised version; it is the usual training set for colorectal tissue classification.
