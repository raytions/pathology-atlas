  • CAMELYON16

    Dataset

    Sentinel lymph node WSIs from two Dutch hospitals with exhaustive metastasis contours, built for the first WSI challenge in computational pathology. Small, well annotated and still the default sanity check for slide-level metastasis detection.

    Organ
    Breast
    Task
    Lymph-node metastasis detection
    Annotation
    Slide label, Lesion contours
    Access
    Open download

    WSI399 slides · 399 patientsCC0

  • CAMELYON17

    Dataset

    A five-centre extension of CAMELYON16 that moves from single slides to patients: slides are grouped into artificial patients and scored by pN stage. Useful for testing robustness across centres and scanners.

    Organ
    Breast
    Task

  • CRC-VAL-HE-7K

    Dataset

    7,180 H&E patches with the same nine tissue classes, size and resolution as NCT-CRC-HE-100K, from colorectal adenocarcinoma patients who do not appear in that set. Released as its external test set, and it is the test split behind most reported colorectal tissue-classification results catalogued here.

    Organ
    Colorectum
    Task
    Colorectal tissue classification
    Annotation
    Patch label
    Access
    Open download

  • NCT-CRC-HE-100K

    Dataset

    100,000 non-overlapping 224 x 224 H&E patches at 0.5 microns per pixel, each labelled with one of nine tissue classes, cut from hand-delineated regions of 86 slides. Released in a colour-normalised version and an unnormalised version; it is the usual training set for colorectal tissue classification.

    Organ
    Colorectum
    Task
    Colorectal tissue classification
    Annotation
    Patch label
    Access
    Open download

    Patch100,000 patches from 86 source slidesCC BY 4.0

  • PANDA

    Dataset

    A large public set of prostate biopsy WSIs with grade labels, released for a 2020 Kaggle competition that the paper describes as the largest histopathology competition to date. Each biopsy has an ISUP grade group and Gleason score; many training slides also carry partial masks whose label scheme differs by contributing centre.

    Organ
    Prostate
    Task
    Gleason grading
    Annotation
    Slide label, Region mask
    Access
    Platform account + rules

    WSI10,616 slides · 2,113 patientsCC BY-SA-NC 4.0

  • SICAPv2

    Dataset

    Prostate core-needle biopsy patches (512 x 512 at 10x) from 155 slides of 95 patients, each with a pixel-level Gleason grade mask, plus a primary and secondary Gleason grade per slide and a patient-level train / validation / test partition proposed by the authors.
