  • ABMIL

    MIL aggregator

    Attention-based deep MIL (ABMIL)

    Frames multiple-instance learning as learning a bag-label distribution and replaces max or mean pooling with a learned attention pooling, so each instance gets an interpretable weight. It is the aggregator many later slide-level models build on or compare against.

    Task family
    Weakly supervised slide classification
    Input → output
    Pre-extracted patch features → Slide-level prediction, Patch attention scores / heatmap

  • CLAM

    MIL aggregator

    Clustering-constrained attention MIL. Learns a slide label from bags of patch features and adds an instance-level clustering loss on the most and least attended patches. The repository is also a widely reused WSI tiling and feature-extraction toolkit.

    Task family
    Weakly supervised slide classification
    Input → output
    Pre-extracted patch features → Slide-level prediction, Patch attention scores / heatmap
    Code
    GPL-3.0
    Weights
    Public download
    Evaluated on
    CAMELYON16, CAMELYON17

  • CONCH

    Foundation model (encoder)

    A vision-language foundation model trained contrastively on about 1.17 million histopathology image-caption pairs. Its ViT-B/16 image encoder gives patch embeddings for supervised heads, and the paired text encoder allows zero-shot classification and retrieval from text prompts.

    Self-supervised representation learning, ROI / patch classification, Weakly supervised slide classification

  • H-optimus-0

    Foundation model (encoder)

    A 1.1-billion-parameter ViT-g/14 tile encoder from Bioptimus, trained with self-supervised learning on a proprietary collection of more than 500,000 H&E whole-slide images. It outputs 1536-dimensional tile embeddings; the release README benchmarks them with linear probes and with attention MIL heads for slide-level tasks.

  • H0-mini

    Foundation model (encoder)

    A ViT-B/14 tile encoder distilled from H-optimus-0 with DINOv2-style self-distillation on about 43 million tiles from 6,093 TCGA slides. The paper reports it as competitive with much larger encoders; it is a separate model with its own, more restrictive licence.

  • Phikon

    Foundation model (encoder)

    A ViT-Base tile encoder from Owkin, trained with iBOT masked-image modelling on about 40 million pan-cancer TCGA tiles. Its successor by name, Phikon-v2, is a ViT-L trained with DINOv2 on a different public dataset, so the two are catalogued as separate models.

  • Prov-GigaPath

    Foundation model (encoder)

    A whole-slide foundation model from Providence and Microsoft: a tile encoder pretrained on about 1.3 billion 256 x 256 tiles from 171,189 slides of the Providence health network, plus a LongNet-based slide encoder that turns tile embeddings and their coordinates into slide-level representations.

  • TransMIL

    MIL aggregator

    Transformer-based correlated MIL. Instead of treating patches as independent samples, it uses self-attention to model correlations between them, aiming to capture both morphological and spatial information before predicting a slide label.

  • UNI

    Foundation model (encoder)

    A ViT-L/16 image encoder pretrained with DINOv2 self-supervision on more than 100 million patches from over 100,000 H&E WSIs. It produces 1024-dimensional patch features that downstream heads (for example attention MIL) turn into slide predictions.
